3. PLACEMENT TEST — RANDOMISED QUESTIONS (Feature fix + expansion)

   Problem: Every test attempt showed the exact same 15 questions.

   Solution — Phase 1 (initial randomisation):
   - Expanded the question bank from 15 to 30 questions (10 grammar, 10 vocab,
     2 reading passages × 5 questions).
   - Added `sampleQuestions()` function that shuffles each bank and picks
     5 grammar + 5 vocab + 1 random reading passage per test.
   - Updated `scorePlacement()` to accept the sampled question set as a
     parameter (was previously hardcoded to the global array).
   - Updated `page.tsx` to call `sampleQuestions()` on "Start the test" and
     store the result in component state.
   - Updated `placement.test.ts` for the new API.

   Problem: After completing the test and navigating back to /placement-test,
   the "Start the test" intro screen was missing (blank page).

   Root cause: On quiz completion, `setPhase('done')` was called before
   `router.push('/placement-test/results')`. Next.js router cache could restore
   this state on back-navigation, skipping the intro guard.

   Fix: Reset all state (phase → 'intro', questions → [], etc.) before pushing
   to results, so the cached state is always the intro screen.

   Solution — Phase 2 (user requested 100 questions per type):
   - Grammar bank expanded to 100 questions (g1–g100).
   - Vocabulary bank expanded to 100 questions (v1–v100).
   - Reading bank expanded to 20 passages × 5 questions = 100 reading questions.

   Final bank: 300 total questions → each test draws 15 (5+5+5).
